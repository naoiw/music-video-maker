## 手動検証用の実行ファイル

通常 CI の windows-desktop Artifact は exe 単体の開発確認用。正式配布ZIPではなく、FFmpeg/FFprobe を別途用意した開発環境で先に W02〜W08 の確認ができる。P01/P02/W01/W09 の代用にはならない。

#24 承認後は Release ワークフローの Run workflow から main または develop とバージョン（v0.1.0）を指定する。手動実行では公開ジョブを起動せず、7日間保持される windows-release Artifact を生成する。GitHub の手動実行にはワークフローが既定ブランチに存在する必要がある。main への取り込みはユーザー承認後とする。

## 既知の制限

[ユーザーガイド](user-guide.md) の対応範囲を参照。画像は1件、MP3は1件、ぼかし背景GIFは静止画。試聴は最大30秒。AAC圧縮後のピーク・ラウドネスの厳密一致は保証しない。強制終了時の一時ファイル回収、未導入WebView2の完全オフライン起動、コード署名、YouTube互換性の実機確認は別途必要。H.264/AACのライセンス・特許等の条件を未確認のまま公開しない。
