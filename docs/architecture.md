# システム構成

## 技術選定

- フロントエンド: TypeScript / HTML / CSS / Vite（フレームワークなしを初期選択）。
- デスクトップ: Tauri 2 / Rust。OS のファイル選択、処理実行、設定保存を担当。
- エンコード: FFmpeg / FFprobe のネイティブ実行。既存のコーデック・フィルタを利用する。
- ブラウザ版: 将来 FFmpeg.wasm などの実行バックエンドを検討する。Tauri の実行ファイルを Pages に置くだけでは動作しない。[ブラウザ版の技術検証](browser-feasibility.md) を参照。公開は別途判断し、FFmpeg WASM バイナリの配布を前提にしない。

## 責務

    GUI (src/)
       ↓ 型付きサービスインターフェース
    Desktop backend (Tauri IPC)
       ↓ 検証済み設定
    Rust (src-tauri/src/)
       ├─ media / probe
       ├─ audio / filter
       ├─ video / encode
       ├─ ffmpeg / process
       └─ settings / local JSON

フロントエンドは Rust 固有 API の呼び出しをサービス層に集約する。ファイル参照はパス固定にせず、将来ブラウザの File/Blob を利用可能な境界を設ける。処理パラメータと UI 状態を分離する。

## 安全性

- シェルを介さず、引数配列で FFmpeg を実行する。
- フィルタは許可済み種類・数値範囲から構築し、任意コマンドを受け付けない。
- 出力先を入力ファイルと同一にせず、上書き確認を行う。
- 一時ファイルは専用作業ディレクトリに置き、中断時に回収する。
- Tauri の capability は必要最小限とし、リモートページにローカル権限を付与しない。
- 実際の楽曲はリポジトリや CI に送らない。

## FFmpeg の利用

利用者が別途インストールした FFmpeg/FFprobe を外部プロセスとして使用する。ソースコードのみを公開し、実行ファイル・FFmpeg の同梱配布は行わない。検出・起動の詳細は [FFmpeg / FFprobe](ffmpeg.md) を参照。

## 検証

設定値・引数生成を単体テストし、合成したテスト素材を使った FFmpeg 結合テストでコーデック・尺・寸法を検証する。Windows の GUI 操作は実機で確認する。

## 音声フィルタ処理

[音声フィルタ処理基盤](audio-filters.md) に共通の型・パラメータ検証・適用順序・FFmpeg グラフ生成を定義する。試聴と動画出力はこの基盤を利用する方針とする（#17、#18）。

## 設定の永続化（#20）

TypeScript のバージョン付き設定スキーマで出力・フィルタ設定を検証し、Tauri IPC 経由で Rust がアプリ専用設定ディレクトリの settings.json に保存する。サイズ上限は16 KiB、書き込みは一時ファイルからの置換。素材パスは保存しない。スキーマとGUIの復元仕様は [基本 UI](ui.md) を参照。

## フィルタプリセット（#21）

既存の設定スキーマから音声フィルタ項目だけを抽出し、名前付きの複数設定を presets.json（version: 1、64 KiB上限）に保存する。settings.json とは独立し、同じ Rust の固定パス・一時ファイル置換処理を利用する。適用時は既存のフィルタ更新と自動保存を再利用する。

## エラー処理（#22）

RustのI/O種別・メディア処理エラーを `[MVM:CODE] 詳細` 形式で分類し、既存の文字列IPCを維持する。フロントエンドの共通エラー処理で操作別の案内と診断詳細に分離する。未知エラーにはフォールバックし、ENCODE_CANCELLEDは従来どおり中断として扱う。診断情報はセッション内の表示に限定する。

## 画像合成（#64）

blurredモードはRust imageクレートで同一素材を背景cover・ガウスぼかし・中央前景に合成する。合成PNGをプレビューIPCで返し、動画生成では保存先と同じファイルシステムに一時PNGを生成してループ入力する。前景・背景を毎フレーム再計算しない。contain/coverのFFmpeg処理は維持する。GIFだけはこの静止画経路をバイパスし、FFmpegのsplit/crop/scale/gblur/overlayで前景と背景を動的合成する。透過は黒に合成する。GIFプレビューは2枚のアニメーション画像のCSS近似表示（元のループ指定に従い、画素や再生同期は完全一致を保証しない）。
