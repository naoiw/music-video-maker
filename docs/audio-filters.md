# 音声フィルタ処理基盤（#13）

Rust の audio_filters モジュールが型付きの設定を FFmpeg の音声フィルタグラフへ変換する。TypeScript の services/audio-filters.ts は同一の設定スキーマを持ち、Tauri IPC を通じて検証結果を取得できる。

## 設定と適用順序

- フィルタ配列の先頭から順に適用する。複数の同じ種類も指定可能。
- 各要素は enabled と filter（kind と数値パラメータ）で構成する。
- 無効な要素はグラフに含めない。空または全無効なら null を返し、-af 自体を指定しない。
- 最大32要素。任意のフィルタ文字列、未知の種類、数値以外のパラメータを拒否する。Rust 側で有効なフィルタの数値範囲と有限性を検証する。
- サンプリング周波数は読み込んだ MP3 の値を使用する。8～48 kHz を対象とし、周波数設定はナイキスト周波数未満に制限する。

| 種類 | FFmpeg | 暫定の許容値 |
| --- | --- | --- |
| noiseReduction | afftdn | 低減量 0.01～30 dB、ノイズフロア -80～-20 dB |
| highPass | highpass | 20～20000 Hz、ナイキスト未満 |
| lowPass | lowpass | 同上 |
| equalizer | equalizer | 同上、Q 0.1～10、ゲイン -24～24 dB |
| gain | volume | -24～24 dB |
| loudness | loudnorm | -24～-10 LUFS、-9～-1 dBTP |
| limiter | alimiter | -12～-0.5 dBFS |

例（無効の要素は無視される）:

    [
      {"enabled":true,"filter":{"kind":"highPass","frequencyHz":80}},
      {"enabled":false,"filter":{"kind":"lowPass","frequencyHz":10000}},
      {"enabled":true,"filter":{"kind":"gain","gainDb":-6}}
    ]

生成結果:

    highpass=f=80,volume=-6dB

このグラフを FFmpeg の -af に1個の引数として渡す。シェルや任意のコマンド文字列は使用しない。

## 検証

単体テストは空・無効・順序・数値検証・JSON スキーマを検証する。FFmpeg 結合テストは合成正弦波で無効時の PCM 一致、2つの -6 dB ゲインの累積効果、5種類のフィルタの組み合わせを確認する。Suno 楽曲の聴感改善・クリッピング対策の確認は後続 Issue で実施する。

    cargo test --manifest-path src-tauri/Cargo.toml audio_filters::tests
    cargo test --manifest-path src-tauri/Cargo.toml audio_filters::tests::processes_ -- --ignored

## ノイズ除去（#14）

FFT ベースの afftdn を使用する。GUI は初期状態で無効。低減量は 1～30 dB（初期値 6 dB）、ノイズフロアは -80～-20 dB（初期値 -50 dB）を1 dB刻みで調整できる。Rust の共通設定検証を通し、設定状態を表示する。初期値は控えめな出発点であり、Suno 楽曲に対する最適値として検証したものではない。

### 合成ノイズによる測定

FFmpeg 7.1.5 の anoisesrc で振幅 0.01、seed 1234、48 kHz、3秒のホワイトノイズを生成した。処理開始直後を避け、中央1秒の浮動小数点 PCM の RMS を比較した。値はこのテスト素材に限定される。

| 低減量 | ノイズフロア | RMS | 原音比（dB） |
| --- | --- | --- | --- |
| 無効 | — | 0.005772 | 0 |
| 6 dB | -45 dB | 0.003093 | -5.42 |
| 12 dB | -45 dB | 0.001888 | -9.71 |
| 12 dB | -60 dB | 0.005610 | -0.25 |
| 30 dB | -20 dB | 0.000183 | -29.99 |

ノイズフロアを高く見積もると弱い音楽成分もノイズとして抑制される可能性がある。強い設定では残響、子音、シンバル等の高域、細部の損失や人工的な音が生じ得る。クリッピングや生成モデルの不自然な音色、MP3 圧縮歪みを完全に修復する機能ではない。音楽には常時有効化せず、原音と比較して最小限の設定を選ぶ。

Suno 楽曲自体の聴感評価は未実施。実素材をリポジトリや CI に送らず、#17 の試聴機能完成後に原音と加工音を比較する。#18 までは MP4 出力にフィルタを適用しない。

自動テストは無効時のグラフ省略、設定範囲、同一合成ノイズに対する低減量・ノイズフロアの差を確認する。

## 周波数フィルタ（#15）

ハイパス、ローパス、パラメトリック EQ を独立して有効化できる。初期状態はすべて無効。配列順はノイズ除去 → ハイパス → ローパス → EQ。HPF/LPF は FFmpeg の既定の2次フィルタ。EQ は1バンド、幅の指定方式は Q とする。

| 設定 | 初期値 | 許容範囲 |
| --- | --- | --- |
| HPF カットオフ | 80 Hz | 20～20000 Hz、ナイキスト未満 |
| LPF カットオフ | 12000 Hz | 同上 |
| EQ 中心周波数 | 1000 Hz | 同上 |
| EQ Q | 1 | 0.1～10 |
| EQ ゲイン | 0 dB | -24～+24 dB |

MP3 読み込み後はサンプルレートに応じて GUI の上限を更新し、不正な設定を表示する。素材変更によって範囲外になった値を勝手に変更せず、リセットまたは手入力で修正する。設定のリセット時は周波数を現在の上限内に収める。未選択時は48 kHzを仮定する。Rust でも全有効フィルタを検証する。空欄や非有限値は無効。

### 周波数応答の測定

FFmpeg 7.1.5、48 kHz、0.5秒の合成正弦波を用い、最初の100 msを除いた RMS 比を dB に換算した。HPF/LPF のカットオフを1000 Hz、EQ を1000 Hz / Q=1 / +6 dB とした場合:

| 入力 | HPF | LPF | EQ |
| --- | ---: | ---: | ---: |
| 100 Hz | -40.15 dB | 0.00 dB | +0.06 dB |
| 1000 Hz | -3.01 dB | -3.01 dB | +6.00 dB |
| 10000 Hz | 0.00 dB | -42.97 dB | +0.05 dB |

EQ の正ゲインや複数フィルタの組み合わせはピーク超過を起こす場合がある。音量・ピーク対策は #16、実素材での試聴は #17、MP4 への適用は #18 で行う。

## 音量調整（#16）

ゲイン、ラウドネス正規化、ピークリミッターを個別に有効化する。初期状態は全無効。処理順はノイズ除去 → HPF → LPF → EQ → ゲイン → 正規化 → リミッター。

| 設定 | 初期値 | 許容範囲 |
| --- | --- | --- |
| ゲイン | 0 dB | -24～+24 dB |
| 目標ラウドネス | -14 LUFS | -24～-10 LUFS |
| 正規化時の True Peak | -1.5 dBTP | -9～-1 dBTP |
| リミッター上限 | -1 dBFS | -12～-0.5 dBFS |

- loudnorm は EBU R128 に基づく1パス動的正規化（linear=false、LRA=11 固定）。元のサンプルレートへ戻すため aresample を続ける。全楽曲で目標 LUFS に厳密一致することは保証しない。2パス測定・線形正規化は未実装。
- alimiter はサンプルピークを制限する。dBFS から線形振幅へ変換し、attack=5 ms、release=50 ms、level=false（自動増幅なし）、latency=true（遅延補償）を指定する。
- ゲイン・正規化を有効にするとGUIはリミッターも有効にする。個別に無効化でき、単独でも有効化できる。正ゲイン・EQ による過大なピークに注意する。
- リミッターは True Peak リミッターではない。インターサンプルピーク、AAC 再エンコード後のピーク、既にクリップした音声の修復は保証しない。正規化後のリミッターによって LUFS が目標から変化する場合もある。

### 合成音の検証

Linux FFmpeg 7.1.5 の48 kHz / 1 kHz正弦波を使用。浮動小数点 PCM のピークと EBU R128 測定値を確認した。

| 条件 | ピーク振幅 | サンプルピーク |
| --- | ---: | ---: |
| 原音 | 0.12497 | 約 -18.1 dBFS |
| +24 dB、保護なし | 1.98063 | 約 +5.9 dBFS |
| +24 dB、-1 dBFS リミッター | 0.89125 | -1.0 dBFS |

6秒の正弦波を -14 LUFS / -1.5 dBTP で正規化した後の EBU R128 測定は -14.0 LUFS。実楽曲の音質と最終 AAC 出力のピークは未検証（#17、#18で確認）。現在は設定と処理基盤までで、動画生成には適用しない。

## 音声試聴（#17）

任意の開始位置から最大30秒を原音・加工音で比較する。原音は空のフィルタ配列、加工音は現在の共通 FilterChain を使用する。FFmpeg で MP3 を再検証し、元のサンプルレート・チャンネル数の16bit PCM WAV を生成する。フィルタ適用後に出力側で区間を選択し、フィルタに先行区間の音声を与える。全曲再生は未実装。

WAV は OS の一時ディレクトリ内に作成し、最大6MiBのサイズ検証後に IPC で返す。一時ディレクトリは Rust の TempDir で通常終了・失敗時に削除する。ブラウザ側では Blob URL を使用し、素材・設定・区間の変更時やページ終了時に破棄する。ファイルシステム全体のアクセス権を追加しない。元の MP3 は変更しない。

同じ区間では両バージョンをキャッシュし、切替時は直前の再生位置を引き継ぐ。フィルタに由来する遅延や端点の違いによりサンプル単位の完全同期は保証しない。最終出力の AAC 圧縮や全曲のラウドネスを正確に再現するものではない。16bit PCM 化により 0 dBFS 超過はクリップするため、ゲイン設定時はピーク保護を確認する。

合成35秒 MP3 に対し、開始2秒から30秒、末尾34秒から1秒の試聴を確認する結合テストを追加。-6 dB の加工音の RMS 比も検証する。実際の Suno 楽曲の聴感比較は Windows 実機で行う。MP4 出力への統合は #18。
