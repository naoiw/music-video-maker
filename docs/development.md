# 開発フロー

## ブランチ

- main: 段階ごとに確認済みの安定版。初期構築・仕様・開発基盤は直接反映可。
- develop: MVP 機能の統合・動作確認用。
- feat/*, fix/*, docs/*, chore/*: develop を起点とする個別 Issue の作業ブランチ。

## 手順

1. 若い Issue から着手する。
2. 初期構築後は develop から作業ブランチを作成する。
3. PR を develop に作成し、差分と利用可能な CI を確認してマージする。
4. develop の動作を確認し、段階ごとに develop → main の PR を作成する。
5. ユーザー確認を経て main へマージし、対象 Issue をクローズする（develop への統合時は自動クローズを前提にしない）。
6. main の変更を develop に取り込み、次の段階へ進む。

## 段階

- #1–#5: 開発基盤
- #6–#12: 基本的な動画生成
- #13–#18: 音声加工
- #19–#23: 操作性・品質
- #24–#27: MVP リリース

#28 以降は MVP 完成後の拡張とする。

## 注意事項

実際の楽曲・画像や個人情報をコミットしない。検証には再配布可能な素材を使用する。FFmpeg のバイナリ配布はライセンス条件の確認後に行う。
