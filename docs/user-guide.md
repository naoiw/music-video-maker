# Music Video Maker ユーザーガイド

Music Video Maker は、MP3 と画像から YouTube 投稿などに使える MP4 を作成する Windows 向けローカル GUI ツールです。Suno の楽曲だけでなく、対応する任意の MP3 を使用できます。素材のアップロードやアカウント登録は必要ありません。

## 1. ソース取得・ビルド・起動

対象は Windows 10 / 11 x64 です。ビルド済みバイナリは公開しません。

1. [リポジトリ](https://github.com/naoiw/music-video-maker) の Code → Download ZIP からソースを取得し、「すべて展開」する（git clone でも可）。
2. `setup.bat` をダブルクリックし、不足するツールの導入を行う。初回はネット接続・インストーラーの操作が必要。
3. セットアップ完了後、必要に応じて Windows を再起動し、`build.bat` をダブルクリックする。
4. `src-tauri/target/release/music-video-maker.exe` をダブルクリックする。以降は GUI で操作する。ソース更新時には再ビルドする。

詳しい手動コマンドと必要環境は [環境構築とビルド](setup.md) を参照。FFmpeg/FFprobe は利用者がインストールしたものを使用する。

## 2. 最初の動画を作る

| 順序 | 操作 |
| --- | --- |
| 1 | 「素材」の「音声」横の「選択」を押し、MP3 を1つ選ぶ。 |
| 2 | 「画像」横の「選択」を押し、PNG / JPG / JPEG / GIF を1つ選ぶ。プレビューを確認する。 |
| 3 | 「出力設定」を確認する。一般的な横長動画なら 1920 × 1080、30 fps、「中央80%・ぼかし背景」、「標準 (CRF 20)」で始める。 |
| 4 | 音声を加工しない場合は、すべての音声フィルタを無効にする。「動画出力」に「音声フィルタ: なし」と表示されることを確認する。 |
| 5 | 「動画出力」の「保存先」横の「選択」を押し、存在するフォルダに未使用の MP4 ファイル名を指定する。 |
| 6 | 「MP4を生成」を押す。進捗が100%になり「生成完了」と表示されるまで待つ。 |
| 7 | 指定したフォルダで MP4 を開き、画像・音声・再生時間を確認する。必要なら YouTube などへ自分で投稿する。 |

MP3 と画像をエクスプローラーからウィンドウへドラッグ＆ドロップしても読み込めます。音声1件と画像1件を同時にドロップすることも可能です。複数の音声、複数の画像、非対応形式を含むドロップは拒否されます。

以前使用した設定が残っている場合は、「出力・フィルタ設定を初期化」を押すと初期値で始められます。原音の MP3 や元画像は変更されません。

## 3. 出力設定

| 項目 | 選択肢 | 選び方 |
| --- | --- | --- |
| 解像度 | 1920 × 1080 (16:9) | 横長動画。初期値。 |
| | 1080 × 1080 (1:1) | 正方形動画。 |
| | 1080 × 1920 (9:16) | 縦長動画。 |
| フレームレート | 24 / 30 / 60 fps | 初期値は30 fps。静止画なら通常30 fpsで十分。GIFの動きに合わせて変更する。 |
| 映像品質 | 高画質 (CRF 16) / 標準 (CRF 20) / 容量優先 (CRF 24) | 数値が小さいほど高画質・大容量になる傾向。初期値は20。 |
| 形式 | MP4 · H.264 / AAC | 固定。音声は AAC 192 kbps、映像は yuv420p、faststart 有効。 |

画像配置は次の3種類です。いずれも元画像の縦横比を維持します。

| 画像配置 | 表示 | GIF の扱い |
| --- | --- | --- |
| 中央80%・ぼかし背景（初期値） | 前景を高さ80%を目標に中央配置。横幅が収まらない場合は縮小し、背景を同じ画像のぼかしで埋める。 | 先頭フレームのみ（静止画） |
| 全体表示（余白） | 画像全体を収め、余った部分を黒帯にする。 | 音声終了までアニメーションを繰り返す。 |
| 画面いっぱい（切り抜き） | 画面全体を覆うように拡大し、はみ出した部分を中央から切り抜く。 | 音声終了までアニメーションを繰り返す。 |

アニメーション GIF のプレビューは元ファイルのループ指定に従いますが、全体表示・切り抜きの MP4 出力では音声終了まで繰り返します。出力時のフレーム間隔は設定 FPS に依存します。

## 4. 音声フィルタ

初期状態はすべて無効です。必要な項目だけチェックを入れて有効にします。次の数値はアプリの初期値であり、どの楽曲にも適した推奨値という意味ではありません。

| フィルタ | 用途 | 初期値 |
| --- | --- | --- |
| ノイズ除去（FFT） | 背景のノイズを抑える。強くすると高音や残響も失われる場合がある。 | 低減量 6 dB、ノイズフロア -50 dB |
| ハイパス（低域カット） | 指定周波数より低い帯域を抑える。 | 80 Hz |
| ローパス（高域カット） | 指定周波数より高い帯域を抑える。 | 12000 Hz |
| パラメトリックEQ | 特定の帯域を増減する。Qが大きいほど対象帯域が狭くなる。 | 中心 1000 Hz、Q 1、ゲイン 0 dB |
| ゲイン調整 | 全体の音量を増減する。 | 0 dB |
| ラウドネス正規化 | 聴感上の音量を目標値に近づける。 | -14 LUFS、True Peak 上限 -1.5 dBTP |
| ピークリミッター | 加工後のサンプルピークを抑える。 | -1 dBFS |

上から表の順に処理します。周波数上限は入力音声のサンプリング周波数によって変わります。ゲイン調整・ラウドネス正規化を有効にするとピークリミッターも有効になりますが、個別に解除できます。

設定例：原音を活かしたい場合は全無効、ノイズが気になる場合はノイズ除去だけを有効にして原音と比較、音量が気になる場合はゲインまたはラウドネス正規化とリミッターを試します。一度に多くの項目を変更せず、必要な範囲で調整してください。既にクリップした音声の修復や、AAC 出力後の True Peak・LUFS の厳密な一致は保証しません。

## 5. 原音と加工音を比較する

1. MP3 を選択する。
2. 「プレビュー」の「音声の試聴・比較」で「試聴区間（最大30秒）」のスライダーを動かす。
3. 「原音」と「加工音」を切り替え、共通の再生コントロールで比較する。
4. フィルタを変更したら「加工音」を選び直して確認する。区間や設定変更時は試聴データが作り直される。
5. 聴感に問題がなければ MP4 を生成する。

試聴と MP4 は同じフィルタ設定を使用します。ただし試聴は最大30秒の WAV、MP4 は全曲の AAC のため、音質・ピーク・ラウドネスが完全に一致するわけではありません。

## 6. 設定の保存とプリセット

解像度・フレームレート・画像配置・映像品質と音声フィルタ設定は自動保存されます。素材や保存先、試聴区間、生成履歴は保存されません。再起動後は素材と保存先を選び直してください。

「フィルタプリセット」では、よく使う音声フィルタ設定を名前付きで管理できます。

- 保存：「プリセット名」を入力し「現在のフィルタを保存」を押す。
- 適用：「保存済みプリセット」から選び「適用」を押す。音声フィルタだけを変更し、素材や出力設定は変更しない。
- 削除：対象を選んで「削除」を押す。現在適用中の設定は維持される。
- 「フィルタを初期化」：全フィルタを無効・初期値に戻す。保存済みプリセットは残る。
- 「全削除」：続けて「全削除を確定」を押すと保存済み一覧だけを削除する。元には戻せないため注意する。

最大50件、名前は前後の空白を除いて1～40 UTF-16コード単位。同じ名前（大文字・小文字の違いを含む）は上書きできません。別名で保存するか古いプリセットを削除してから保存します。既製のプリセットはありません。

「出力・フィルタ設定を初期化」は出力設定と音声フィルタを初期状態へ戻します。素材、保存先、保存済みプリセットは維持します。

設定は `%APPDATA%\win.tiym.music-video-maker` 内の settings.json、プリセットは同じ場所の presets.json に保存されます。エクスプローラーのアドレスバーから開けます。設定を引き継ぐ場合はアプリを終了してからこの2ファイルをバックアップしてください。

## 7. 生成の中断・再実行

生成中は素材と設定の変更が制限されます。「中断」が有効な間は処理を中止できます。中断処理が終わるまで待ってから再実行してください。最終保存中は中断できません。100% は検証と保存が完了したことを示します。

既存の MP4 を上書きすることはありません。生成に失敗した場合は画面の案内に沿って素材や設定を見直し、再実行してください。成功後に別の動画を作る場合は保存先を指定し直してください。通常の失敗・中断時は一時ファイルを回収しますが、アプリや OS の強制終了時は保証しません。

## 8. トラブルシューティング

| 症状 | 確認・対処 |
| --- | --- |
| アプリが起動しない | Windows x64 か、build.bat が成功したか、WebView2 Runtime が導入されているかを確認する。 |
| MP3の選択や生成ができない | 画面下部の「実行環境」を開き、FFmpeg と FFprobe の検出状態を確認する。setup.bat を実行し、PATH の反映後にアプリを再起動する。 |
| MP3を読み込めない | ローカルで再生できる正常な MP3 を選び直す。別形式の拡張子だけを .mp3 に変更しても対応しない。 |
| 画像を読み込めない | PNG/JPEG/GIF、32 MiB以下、4000万画素以下か確認する。破損・非対応画像は別の画像に置き換える。 |
| GIFが動かない | 画像配置を「全体表示（余白）」か「画面いっぱい（切り抜き）」にする。 |
| 「MP4を生成」が押せない | 音声、画像、保存先、FFmpeg/FFprobe の状態、有効フィルタの空欄・範囲外設定を確認する。 |
| 保存できない／同名ファイルがある | 書き込み可能な既存フォルダを選び、別のファイル名にする。素材が移動していないか、他のアプリでファイルを開いていないかも確認する。 |
| 容量不足 | 保存先と一時ファイル用ドライブの空き容量を確保する。フィルタ有効時は中間 WAV が必要で、48 kHz ステレオでは約23 MB/分が追加で必要になる。 |
| 生成結果の形式・再生時間が一致しない | 不完全な出力は保存しない。別の正常な MP3、フィルタ全無効で試し、FFmpeg の検出情報とエラーコードを確認する。 |
| 試聴できない／音質が変わりすぎる | 原音と加工音を比較し、フィルタを弱めるか初期化して再試聴する。 |
| 設定・プリセットの読み書きに失敗 | 設定フォルダの権限と空き容量を確認する。破損したプリセットはバックアップ後に「全削除」で復帰できる。 |

### 解決しない場合

画面下部の「診断情報（直近8件）」を開き、発生時刻・操作・エラーコード・詳細を確認します。[GitHub Issues](https://github.com/naoiw/music-video-maker/issues) に報告する場合は、アプリのバージョン、Windows のバージョン、FFmpeg/FFprobe の検出情報、再現手順、出力設定と有効なフィルタ、エラーコードを添えてください。

診断情報には個人のファイルパスが含まれる場合があります。共有前に個人情報を取り除き、楽曲・画像そのものや個人情報は公開しないでください。診断情報はアプリ内で保持され、外部送信・自動ファイル保存はされません。

## 9. 対応範囲と制約

- 入力：MP3 1件、PNG/JPG/JPEG/GIF 1件。画像は32 MiB以下、4000万画素以下。
- 出力：H.264 / AAC の MP4。出力解像度・FPS・品質は上記の選択肢のみ。
- 音声の元ファイルや画像を外部に送信しない。アプリは YouTube へのアップロードや投稿を行わない。
- ブラウザ版、MP4/WebM の入力、WAV/FLAC の入力、複数レイヤー、歌詞表示、一括生成、AIノイズ除去、GPUエンコード、macOS/Linux の正式配布は現時点の MVP 対象外。
- YouTube での実際の投稿・再生、Windows クリーン環境でのセットアップ・ビルド・起動は初回リリース前の総合確認事項。現時点で確認済みとはしない。
- 利用する楽曲や画像は投稿・利用に必要な権利を確認する。

開発者向けの詳細は [MVP仕様](specification.md)、[音声フィルタ処理基盤](audio-filters.md)、[環境構築とビルド](setup.md) を参照してください。
