# Music Video Maker ユーザーガイド

Music Video Maker は、音声と画像・動画から YouTube 投稿などに使える MP4 を作成する デスクトップ向けローカル GUI ツールです。Suno の楽曲だけでなく、対応する任意の音声素材 を使用できます。素材のアップロードやアカウント登録は必要ありません。

## 1. ソース取得・ビルド・起動

対象は Windows 10 / 11 x64、macOS（Apple Silicon / Intel）、Ubuntu 24.04 x64（追加対象の実機GUIは要確認）です。ビルド済みバイナリは公開しません。Windows の手順は以下。macOS / Linux は Node.js 26、rustup 等を用意して `bash setup.sh`、`bash build.sh`、`bash run.sh` を実行します。[環境構築とビルド](setup.md) を参照。

1. [リポジトリ](https://github.com/naoiw/music-video-maker) の Code → Download ZIP からソースを取得し、「すべて展開」する（git clone でも可）。
2. `setup.bat` をダブルクリックし、不足するツールの導入を行う。初回はネット接続・インストーラーの操作が必要。
3. セットアップ完了後、必要に応じて Windows を再起動し、`build.bat` をダブルクリックする。pnpm と固定 lockfile を使用してビルドする。
4. `src-tauri/target/release/music-video-maker.exe` をダブルクリックする。以降は GUI で操作する。ソース更新時には再ビルドする。

詳しい手動コマンドと必要環境は [環境構築とビルド](setup.md) を参照。FFmpeg/FFprobe は利用者がインストールしたものを使用する。

## 2. 最初の動画を作る

| 順序 | 操作 |
| --- | --- |
| 1 | 「素材」の「音声」横の「選択」を押し、音声素材を1つ選ぶ。 |
| 2 | 「ベース映像素材」横の「選択」を押し、対応する画像・動画を1つ選ぶ。必要に応じて「追加レイヤー」で画像を重ね、プレビューを確認する。 |
| 3 | 「出力設定」を確認する。一般的な横長動画なら 1920 × 1080、30 fps、「中央80%・ぼかし背景」、「標準 (CRF 20)」で始める。 |
| 4 | 音声を加工しない場合は、すべての音声フィルタを無効にする。「動画出力」に「音声フィルタ: なし」と表示されることを確認する。 |
| 5 | 「動画出力」の「保存先」横の「選択」を押し、存在するフォルダに未使用の MP4 ファイル名を指定する。 |
| 6 | 「MP4を生成」を押す。進捗が100%になり「生成完了」と表示されるまで待つ。 |
| 7 | 指定したフォルダで MP4 を開き、画像・音声・再生時間を確認する。必要なら YouTube などへ自分で投稿する。 |

音声素材・ベース映像素材・追加レイヤーの対応エリアへ1ファイルずつドラッグ＆ドロップできます。音声エリアに MP4 / WebM / MOV / MKV を入れると音声のみ、映像エリアに入れると映像のみを使用します。追加レイヤーは「追加」ボタンでも選択できます。複数ファイルの同時ドロップは受け付けません。

以前使用した設定が残っている場合は、「出力・フィルタ設定を初期化」を押すと初期値で始められます。元の音声・映像ファイルは変更されません。

## 3. 出力設定

| 項目 | 選択肢 | 選び方 |
| --- | --- | --- |
| 解像度 | 1920 × 1080 (16:9) | 横長動画。初期値。 |
| | 1080 × 1080 (1:1) | 正方形動画。 |
| | 1080 × 1920 (9:16) | 縦長動画。 |
| フレームレート | 24 / 30 / 60 fps | 初期値は30 fps。静止画なら通常30 fpsで十分。GIFの動きに合わせて変更する。 |
| 映像品質 | 高画質 (CRF 16) / 標準 (CRF 20) / 容量優先 (CRF 24) | 数値が小さいほど高画質・大容量になる傾向。初期値は20。 |
| 形式 | MP4 · H.264 / AAC | 固定。音声は AAC 192 kbps、映像は yuv420p、faststart 有効。 |

ベース映像素材配置は次の3種類です。いずれも元画像の縦横比を維持します。

| 画像配置 | 表示 | GIF の扱い |
| --- | --- | --- |
| 中央80%・ぼかし背景（初期値） | 前景を高さ80%を目標に中央配置。横幅が収まらない場合は縮小し、背景を同じ画像のぼかしで埋める。 | 音声終了までループ（前景・背景ともアニメーション） |
| 全体表示（余白） | 画像全体を収め、余った部分を黒帯にする。 | 音声終了までアニメーションを繰り返す。 |
| 画面いっぱい（切り抜き） | 画面全体を覆うように拡大し、はみ出した部分を中央から切り抜く。 | 音声終了までアニメーションを繰り返す。 |

アニメーション GIF のプレビューは元ファイルのループ指定に従いますが、すべての画像配置の MP4 出力では音声終了まで繰り返します。ぼかし背景のGIFプレビューはTauriのWebView上の近似表示で、出力と完全な画素一致を保証しません。出力時のフレーム間隔は設定 FPS に依存します。

### 追加レイヤーの編集

ベース映像素材を選択した後、「追加レイヤー」の「追加」を押して 対応する画像・動画を1件ずつ選びます（最大8枚）。リストの上が最前面です。「前面へ」「背面へ」で重なり順を変更し、「削除」で取り除きます。

X・Y位置と幅・高さは出力画面に対する百分率です。例えば X=25、Y=25、幅=50、高さ=50 で画面中央の半分の矩形を指定し、画像は縦横比を保ってその中に収まります。不透明度は0%で不可視、100%で元画像の透過を維持します。位置とサイズの合計が100%を超える場合などは生成できません。

追加GIF・動画もMP4では音声終了までアニメーションを繰り返します。プレビューは元のGIFのループ設定に従います。画像配置の設定はベース映像素材にだけ適用されます。レイヤーは再起動後に保存されません。

## 4. 音声フィルタ

初期状態はすべて無効です。必要な項目だけチェックを入れて有効にします。次の数値はアプリの初期値であり、どの楽曲にも適した推奨値という意味ではありません。

| フィルタ | 用途 | 初期値 |
| --- | --- | --- |
| ノイズ除去（FFT） | 背景のノイズを抑える。強くすると高音や残響も失われる場合がある。 | 低減量 6 dB、ノイズフロア -50 dB |
| ハイパス（低域カット） | 指定周波数より低い帯域を抑える。 | 80 Hz |
| ローパス（高域カット） | 指定周波数より高い帯域を抑える。 | 12000 Hz |
| パラメトリックEQ | 特定の帯域を増減する。Qが大きいほど対象帯域が狭くなる。 | 中心 1000 Hz、Q 1、ゲイン 0 dB |
| ゲイン調整 | 全体の音量を増減する。 | 0 dB |
| ラウドネス正規化 | 聴感上の音量を目標値に近づける。 | -14 LUFS、True Peak 上限 -1.5 dBTP |
| ピークリミッター | 加工後のサンプルピークを抑える。 | -1 dBFS |

上から表の順に処理します。周波数上限は入力音声のサンプリング周波数によって変わります。ゲイン調整・ラウドネス正規化を有効にするとピークリミッターも有効になりますが、個別に解除できます。

設定例：原音を活かしたい場合は全無効、ノイズが気になる場合はノイズ除去だけを有効にして原音と比較、音量が気になる場合はゲインまたはラウドネス正規化とリミッターを試します。一度に多くの項目を変更せず、必要な範囲で調整してください。既にクリップした音声の修復や、AAC 出力後の True Peak・LUFS の厳密な一致は保証しません。

## 5. 原音と加工音を比較する

1. 音声素材を選択する。
2. 「プレビュー」の「音声の試聴・比較」で「試聴区間（最大30秒）」のスライダーを動かす。
3. 「原音」と「加工音」を切り替え、共通の再生コントロールで比較する。
4. フィルタを変更したら「加工音」を選び直して確認する。区間や設定変更時は試聴データが作り直される。
5. 聴感に問題がなければ MP4 を生成する。

試聴と MP4 は同じフィルタ設定を使用します。ただし試聴は最大30秒の WAV、MP4 は全曲の AAC のため、音質・ピーク・ラウドネスが完全に一致するわけではありません。

## 6. 設定の保存とプリセット

解像度・フレームレート・画像配置・映像品質と音声フィルタ設定は自動保存されます。素材や保存先、試聴区間、生成履歴は保存されません。再起動後は素材と保存先を選び直してください。

「フィルタプリセット」では、よく使う音声フィルタ設定を名前付きで管理できます。

- 保存：「プリセット名」を入力し「現在のフィルタを保存」を押す。
- 適用：「保存済みプリセット」から選び「適用」を押す。音声フィルタだけを変更し、素材や出力設定は変更しない。
- 削除：対象を選んで「削除」を押す。現在適用中の設定は維持される。
- 「フィルタを初期化」：全フィルタを無効・初期値に戻す。保存済みプリセットは残る。
- 「全削除」：続けて「全削除を確定」を押すと保存済み一覧だけを削除する。元には戻せないため注意する。

最大50件、名前は前後の空白を除いて1～40 UTF-16コード単位。同じ名前（大文字・小文字の違いを含む）は上書きできません。別名で保存するか古いプリセットを削除してから保存します。既製のプリセットはありません。

「出力・フィルタ設定を初期化」は出力設定と音声フィルタを初期状態へ戻します。素材、保存先、保存済みプリセットは維持します。

設定は Tauri のアプリ設定ディレクトリ内の settings.json、プリセットは同じ場所の presets.json に保存されます。Windows は `%APPDATA%\win.tiym.music-video-maker`、macOS は `~/Library/Application Support/win.tiym.music-video-maker`、Linux は `$XDG_CONFIG_HOME/win.tiym.music-video-maker`（未設定時は `~/.config/win.tiym.music-video-maker`）です。設定を引き継ぐ場合はアプリを終了してからこの2ファイルをバックアップしてください。

## 7. 生成の中断・再実行

生成中は素材と設定の変更が制限されます。「中断」が有効な間は処理を中止できます。中断処理が終わるまで待ってから再実行してください。最終保存中は中断できません。100% は検証と保存が完了したことを示します。

既存の MP4 を上書きすることはありません。生成に失敗した場合は画面の案内に沿って素材や設定を見直し、再実行してください。成功後に別の動画を作る場合は保存先を指定し直してください。通常の失敗・中断時は一時ファイルを回収しますが、アプリや OS の強制終了時は保証しません。

## 8. トラブルシューティング

| 症状 | 確認・対処 |
| --- | --- |
| アプリが起動しない | OSに合ったビルド手順と依存関係を確認する。Windows は WebView2、Linux は WebKitGTK 4.1、macOS/Linux はターミナルから run.sh で起動する。 |
| 音声の選択や生成ができない | 画面下部の「実行環境」を開き、FFmpeg と FFprobe の検出状態を確認する。OSに合った setup.bat / setup.sh を実行し、PATH の反映後にアプリを再起動する。 |
| 音声を読み込めない | 対応形式・音声ストリーム・サンプルレート・チャンネル数を確認する。拡張子のみを変更しても別のコンテナ形式は受理しない。 |
| 画像を読み込めない | 対応画像（32 MiB以下）・動画（2 GiB以下）、4000万画素以下か確認する。破損・非対応画像は別の画像に置き換える。 |
| GIFが動かない | 元GIFが複数フレームを含むか確認する。プレビューが有限回で止まっても、MP4出力は音声終了まで繰り返す。 |
| 「MP4を生成」が押せない | 音声、画像、保存先、FFmpeg/FFprobe の状態、有効フィルタや追加レイヤーの空欄・範囲外設定を確認する。 |
| 保存できない／同名ファイルがある | 書き込み可能な既存フォルダを選び、別のファイル名にする。素材が移動していないか、他のアプリでファイルを開いていないかも確認する。 |
| 容量不足 | 保存先と一時ファイル用ドライブの空き容量を確保する。フィルタ有効時は中間 WAV が必要で、48 kHz ステレオでは約23 MB/分が追加で必要になる。 |
| 生成結果の形式・再生時間が一致しない | 不完全な出力は保存しない。別の正常な音声素材、フィルタ全無効で試し、FFmpeg の検出情報とエラーコードを確認する。 |
| 試聴できない／音質が変わりすぎる | 原音と加工音を比較し、フィルタを弱めるか初期化して再試聴する。 |
| 設定・プリセットの読み書きに失敗 | 設定フォルダの権限と空き容量を確認する。破損したプリセットはバックアップ後に「全削除」で復帰できる。 |

### 解決しない場合

画面下部の「診断情報（直近8件）」を開き、発生時刻・操作・エラーコード・詳細を確認します。[GitHub Issues](https://github.com/naoiw/music-video-maker/issues) に報告する場合は、アプリのバージョン、OS・CPUの情報、FFmpeg/FFprobe の検出情報、再現手順、出力設定と有効なフィルタ、エラーコードを添えてください。

診断情報には個人のファイルパスが含まれる場合があります。共有前に個人情報を取り除き、楽曲・画像そのものや個人情報は公開しないでください。診断情報はアプリ内で保持され、外部送信・自動ファイル保存はされません。

## 9. 対応範囲と制約

- 入力：MP3 / PCM WAV / FLAC / AAC / M4A / MP4 / WebM / MOV / MKV の音声素材1件（8～48 kHz、1～2ch）、PNG / JPEG / GIF / 静止画 WebP / MP4 / WebM / MOV / MKV のベース映像素材1件と追加レイヤー最大8件。画像・GIFは32 MiB以下、動画は2 GiB以下、いずれも4000万画素以下。
- 出力：H.264 / AAC の MP4。出力解像度・FPS・品質は上記の選択肢のみ。
- 音声の元ファイルや画像を外部に送信しない。アプリは YouTube へのアップロードや投稿を行わない。
- アニメーションWebP、Ogg/Opus単体入力、AIノイズ除去、GPUエンコードは環境依存の実験的機能。全OSでバイナリ・インストーラー配布は対象外。歌詞表示（#37）と一括生成（#38）は対応予定なし。
- YouTube での実際の投稿・再生、Windows クリーン環境でのセットアップ・ビルド・起動は初回リリース前の総合確認事項。現時点で確認済みとはしない。
- 利用する楽曲や画像は投稿・利用に必要な権利を確認する。

開発者向けの詳細は [MVP仕様](specification.md)、[音声フィルタ処理基盤](audio-filters.md)、[環境構築とビルド](setup.md) を参照してください。

### 対応する入力コーデック

| コンテナ | 音声として利用 | 映像として利用 |
| --- | --- | --- |
| MP3 / WAV / FLAC / AAC | MP3 / PCM / FLAC / AAC | ― |
| M4A | AAC・ALAC | ― |
| MP4 / MOV | AAC・ALAC・MP3・Opus・FLAC | H.264・HEVC・AV1・MPEG-4 |
| WebM | Opus・Vorbis | VP8・VP9・AV1 |
| MKV | AAC・FLAC・MP3・Opus・Vorbis・ALAC | H.264・HEVC・AV1・VP8・VP9・MPEG-4 |
| PNG / JPEG / GIF / 静止画 WebP | ― | 画像 |

利用中の FFmpeg でデコード可能なことが条件です。コンテナ内の最初の音声、または最初の非添付映像を採用し、該当トラックが存在しない・非対応の場合はエラーになります。動画プレビューは元動画の最初の最大8秒を10fps・360px以内の無音GIFに変換して繰り返します。これは近似表示で、色・透過・フレーム間隔・ループ境界は実出力と異なる場合があります。MP4出力では元動画の映像を音声終了まで使用します。アニメーションWebPは明示的に拒否されます。

コンテナの音声トラックに再生時間情報がない場合と生AACは、選択時に音声をデコードして尺を測定します。PCMを保存せず計測するため、長い素材では読み込みに時間がかかる場合があります。コンテナ全体の長さを音声尺として代用しません。映像・音声の出力尺は加工の有無にかかわらず検証します。


## GPUハードウェアエンコード（#40）

出力設定の「エンコーダー」で CPU (libx264)、GPU 自動選択、利用可能な GPU を選択する。CPU が初期値。GPU は起動時に短い試験エンコードで検出し、「GPU を再検出」で確認し直せる。Windows は NVIDIA NVENC / Intel Quick Sync / AMD AMF、macOS は VideoToolbox、Linux は NVENC / QSV を候補とする。Linux VA-API 等は今回対象外。FFmpeg のビルド・GPU・ドライバにより利用可否は異なる。

GPU 選択時は生成開始時に実際の解像度・FPS・品質で再試験する。利用不可・GPU処理失敗・出力形式/尺の不一致の場合は、CPU で最大1回再試行する。ディスク不足、アクセス権限、素材破損、中断は原則再試行しない。生成結果には実際のエンコーダーと総所要時間、CPUに切り替えた場合はその旨と診断情報を表示する。既存のファイル上書き防止と出力検証を維持する。

映像品質は高画質 / 標準 / 容量優先の3段階。CPUは従来の CRF 16 / 20 / 24、GPUでは対応するエンコーダー固有の設定を使用する。同じ段階でも圧縮率や画質は一致しない。ぼかし、レイヤー合成、音声処理は従来どおり CPU 処理であり、総生成時間の短縮は保証しない。GPUの速度や実楽曲の画質は実機でCPU出力と比較する。

## 音声解析（#33・#34）
音声選択・フィルタ設定後、右列の音声解析で「全曲を解析」を押す。原音・加工音の全曲波形は同一時間軸・同一振幅倍率で比較し、Peak/RMS（dBFS）と0 dBFSを超えたサンプル数を表示する。波形をクリックすると最大30秒の試聴開始位置が変わる。元の試聴区間スライダーも使用可能。FFTは4096点、Hann窓、全曲の平均パワースペクトラム、対数周波数軸20Hz〜ナイキスト周波数。フィルタ変更・素材変更後は結果を破棄して再解析を促す。解析中はMP4出力を開始できない。60分超の音源は解析のみ対象外。原音/加工音のPCM（AAC圧縮前）の比較であり、出力MP4には描画しない。再生中に変化するスペクトラムやスペクトログラムは今回対象外。

## オーディオビジュアライザー（#36）
ベース映像素材を選択した後、「追加レイヤー」の「ビジュアライザー追加」を押す。素材レイヤーと合わせて最大8件。表示形式（周波数バー・音声波形・音量メーター・スペクトログラム）、連動対象（原音・加工音、既定は加工音）、色、背景（黒背景または黒色キーによる透過）、位置・サイズ・不透明度・重ね順を設定する。スペクトログラムはmagma配色固定。透過の場合、黒色に近い表示内容も除去されるため透過背景では明るい色を推奨する。黒背景では黒色の描画も背景に溶け込む。初期配置は下部80%幅・20%高さ。プレビューは配置と色の静止イメージであり実音源に同期したプレビューではない。出力MP4にのみ音声に連動する動きが描画される。ビジュアライザーは指定矩形へ伸縮する。試聴・音声解析の結果は変更しない。

生成時は選択した音声のPCMと有限長の無音FFV1/MKV一時映像を保存先フォルダ内で生成し、その後通常の合成・エンコードを行う。生成中は一時ディスク容量が必要（曲の尺・表示形式・FPS・レイヤー数で変動）。中断やエラー時は一時ファイルを破棄する。出力音声は常に現在のフィルタ設定を適用した音声で、連動対象を原音にしても原音が別音声として混入しない。GPU選択は最終H.264エンコードのみ。FFmpegに各ビジュアライザーフィルタとFFV1が必要。
