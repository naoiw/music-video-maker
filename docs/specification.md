# MVP 仕様（v0.1.0）

## 目的

ローカル PC で楽曲と画像を合成し、YouTube に投稿できる MP4 を GUI から生成する。

## 対象

Windows 10/11 x64 を初期対象とする。素材は外部へ送信しない。Suno 専用の API は使用しない。

| 項目 | MVP |
| --- | --- |
| 音声 | MP3 1 ファイル |
| 映像 | PNG / JPEG / アニメーション GIF 1 ファイル |
| 出力 | MP4、H.264、AAC、yuv420p、faststart |
| 解像度 | 1920×1080、1080×1080、1080×1920 |
| FPS | 24 / 30 / 60（初期値 30） |
| 画像 | アスペクト比維持、中央80%・ぼかし背景（既定）、余白、切り抜き。GIFは全配置で音声終了までループ（ぼかし背景もアニメーション） |
| 音声 | ノイズ除去、ハイパス、ローパス、EQ、ゲイン、正規化、ピークリミッター（任意適用） |
| 操作 | 素材選択、試聴、設定の保存・復元・初期化、出力先選択、進捗表示、中断 |

## 既定値

1920×1080、30 FPS、中央80%・ぼかし背景、H.264 CRF 20、AAC 192 kbps を初期値とする。フィルタはすべて無効から開始し、原音を上書きしない。

## 完了条件

- 対応素材すべてで音声尺に合わせた MP4 が生成される。
- フィルタ有無とパラメータが出力およびプレビューに反映される（#18、同じグラフを使用。試聴は最大30秒の WAV、出力は全曲 AAC）。
- 失敗・中断時に再操作でき、不完全な出力を残さない。代表的な異常に対処方法と診断情報を表示する（#22）。
- 出力・音声フィルタ設定が再起動後に復元され、破損設定から初期値に復帰できる（#20）。
- 名前付きの音声フィルタプリセットを複数保存・適用・削除・初期化できる（#21）。
- 設定・引数・素材・音声加工・動画生成の主要テストがCIで実行され、FFprobeで保存済みMP4を検証できる（#23）。
- 利用者が setup.bat / build.bat で初回環境構築・ビルドを行い、以降は exe から GUI 操作できる。FFmpeg は別途導入する。
- 実際の楽曲で音質と YouTube 互換性を確認する。

## MVP 対象外

MVP 当初は複数レイヤー、動画素材、AI フィルタ、波形表示、バッチ処理、GPU エンコード、macOS/Linux 配布を対象外としていた。複数レイヤーは Post-MVP の #30 で対応済み（下記）。動画素材・音声入力形式の追加は下記 #31・#32 の仕様を参照。

## Post-MVP：追加レイヤー（#30）

ベース画像に PNG / JPEG / GIF を最大8枚追加できる。ベース画像の3種類の配置は維持する。追加レイヤーは奥から手前へ合成し、左上原点の X/Y、幅・高さ（0.01%単位）、不透明度（0～100%）を指定する。矩形はキャンバス内に収め、画像はアスペクト比を維持して矩形内で中央配置する。素材のアルファ値に不透明度を乗算する。プレビューと動画出力に反映し、生成中は変更不可。追加GIFも音声終了までループする。素材とレイヤー設定はセッション内のみ保持する。対応入力形式は下記の拡張仕様を参照。

## Post-MVP：音声入力と用途別ドロップ（#31 / #32）

MP3、PCM WAV、FLAC、AAC、M4A（AAC/ALAC）、MP4/MOV（AAC/ALAC/MP3/Opus/FLAC）、WebM（Opus/Vorbis）、MKV（AAC/FLAC/MP3/Opus/Vorbis/ALAC）の最初の音声トラックを使用する。音声は8～48 kHz、1～2ch。拡張子・コンテナ・コーデックを検証し、音声以外のストリームは出力しない。音声・ベース映像素材・追加レイヤーのドロップ先を分離し、1ファイルずつ選択する。

## Post-MVP：映像入力（#31）

PNG / JPEG / GIF / 静止画 WebP / MP4 / WebM / MOV / MKV をベース・追加レイヤーとして使用できる。動画の最初の非添付映像ストリームだけを採用し、元音声等を混ぜない。短い動画は音声終了まで繰り返し、長い動画は切り詰める。元の動画を出力に使用し、プレビューは最大8秒・10fps・360px以内の無音GIF近似表示とする。動画最大2 GiB、画像最大32 MiB、寸法は4000万画素以下。アニメーションWebPは静止画にせず拒否する。対応コーデックはユーザーガイド参照。最初の対象ストリームが非対応なら明示的なエラーとする。

音声尺が動画コンテナの音声トラックから取得できない場合、および生AACの場合は、音声だけをデコードして尺を測定する。動画全体の長さを代用しない。加工なし・ありの両経路で出力尺を音声尺と比較し、許容差0.2秒を超える出力を公開しない。

## Post-MVP：macOS / Linux（#39）

Windowsのsetup.bat / build.batを維持し、macOS（Apple Silicon / Intel）・Ubuntu 24.04 x64ではsetup.sh / build.sh / run.shを利用する。Node・pnpm・Cargo lockfileの方針は共通。TauriネイティブビルドとFFmpegの全結合テストを各OSのCIで実行する。ソースのみ公開し、macOS署名・公証・アプリバンドルやLinuxパッケージの生成・配布は対象外。追加OSの実機GUIは要確認。
