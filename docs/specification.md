# MVP 仕様（v0.1.0）

## 目的

ローカル PC で楽曲と画像を合成し、YouTube に投稿できる MP4 を GUI から生成する。

## 対象

Windows 10/11 x64 を初期対象とする。素材は外部へ送信しない。Suno 専用の API は使用しない。

| 項目 | MVP |
| --- | --- |
| 音声 | MP3 1 ファイル |
| 映像 | PNG / JPEG / アニメーション GIF 1 ファイル |
| 出力 | MP4、H.264、AAC、yuv420p、faststart |
| 解像度 | 1920×1080、1080×1080、1080×1920 等、偶数寸法 |
| FPS | 24 / 30 / 60（初期値 30） |
| 画像 | アスペクト比維持、余白または切り抜き、GIF は音声終了までループ |
| 音声 | ノイズ除去、ハイパス、ローパス、EQ、ゲイン、正規化（任意適用） |
| 操作 | 素材選択、試聴、設定、出力先選択、進捗表示、中断 |

## 既定値

1920×1080、30 FPS、余白方式、H.264 CRF 20、AAC 192 kbps を初期候補とする。フィルタはすべて無効から開始し、原音を上書きしない。

## 完了条件

- 対応素材すべてで音声尺に合わせた MP4 が生成される。
- フィルタ有無とパラメータが出力およびプレビューに反映される（#18、同じグラフを使用。試聴は最大30秒の WAV、出力は全曲 AAC）。
- 失敗・中断時に再操作でき、不完全な出力を残さない。
- 配布物から開発ツールなしで操作できる。
- 実際の楽曲で音質と YouTube 互換性を確認する。

## MVP 対象外

ブラウザ版、複数レイヤー、動画素材、AI フィルタ、波形表示、バッチ処理、GPU エンコード、macOS/Linux 配布（#28 以降）。
