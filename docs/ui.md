# 基本 UI

- 素材、出力設定、音声フィルタ、プレビュー、動画出力を一画面に配置。
- 幅に応じて二列から一列へ切り替える。
- ブラウザでも UI の確認は可能だが、ネイティブ処理は提供しない。
- 素材選択、設定、試聴、生成等の操作は対応機能が実装されるまで無効にする。
- FFmpeg / FFprobe の検出状態は実行環境欄に表示する。

## 確認項目

- デスクトップとブラウザで表示が崩れない。
- 未実装の操作・素材未選択状態で生成が開始されない。
- 狭い画面で各パネルが一列となり、横スクロールが発生しない。

## 音声読み込み（#7）

- デスクトップ版で FFprobe が検出された場合に MP3 選択を有効にする。
- OS のファイル選択ダイアログから MP3 を 1 ファイル選択する。
- ファイル名、再生時間、サンプリング周波数、チャンネル数、取得できる場合はビットレートを表示する。
- 拡張子だけでなく FFprobe の認識結果とメタデータを検証する。音声全体のデコード検証は行わない。
- 選択のキャンセルや読み込み失敗時は直前の有効な選択を保持する。
- ブラウザプレビュー、FFprobe が未検出の環境では選択できない。

### Windows での確認

1. FFprobe を PATH または実行ファイルの隣に配置し、デスクトップ版を起動する。
2. 正常な MP3、空ファイル、MP3 に改名した WAV、空白・日本語を含むパスを試す。
3. 再選択、キャンセル、失敗時の表示と直前の選択保持を確認する。

## 画像読み込み（#8）

- デスクトップ版で OS のダイアログから PNG、JPG/JPEG、GIF を 1 ファイル選択する。
- Rust の image クレートで実際の形式と画像寸法を検証し、ファイル名、形式、寸法、容量を表示する。
- 選択した画像データのみを IPC で受け渡し、プレビューを描画する。画像のためにファイルシステム全体を WebView に公開しない。FFmpeg の検出状況に関係なく利用できる。
- プレビューはアスペクト比を維持する。アニメーション GIF は元のループ指定に従って再生する。動画への繰り返し合成は #10 で対応する。
- 暫定の読み込み上限は 32 MiB / 4000 万画素。大きなファイルの扱いは必要に応じて再検討する。
- 不正な形式、空ファイル、寸法の異常、プレビューのデコード失敗を拒否する。ただし GIF 全フレームの完全な検証は行わない。
- キャンセルや失敗の場合は直前の有効な素材とプレビューを保持する。

### Windows での確認

1. PNG、JPEG、複数フレームの GIF を順に選択し、寸法・容量とプレビューを確認する。
2. 縦長・横長・正方形の画像が枠内に収まり、縦横比を保つことを確認する。
3. 日本語や空白を含むパス、空ファイル、拡張子を偽装したファイル、破損画像を試す。
4. 選択のキャンセルや読み込み失敗で、直前の選択が維持されることを確認する。
