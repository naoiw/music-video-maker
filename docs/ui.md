# 基本 UI

- 素材、出力設定、音声フィルタ、プレビュー、動画出力を一画面に配置。
- 幅に応じて二列から一列へ切り替える。
- ブラウザでも UI の確認は可能だが、ネイティブ処理は提供しない。
- 素材選択・設定・試聴・生成等の操作は実行環境、選択済み素材、設定値、処理中の状態に応じて有効化する。
- FFmpeg / FFprobe の検出状態は実行環境欄に表示する。

## 確認項目

- デスクトップとブラウザで表示が崩れない。
- 未実装の操作・素材未選択状態で生成が開始されない。
- 狭い画面で各パネルが一列となり、横スクロールが発生しない。

## 音声読み込み（#7）

- デスクトップ版で FFprobe が検出された場合に 音声素材選択を有効にする。
- OS のファイル選択ダイアログから 対応音声素材を1ファイル選択する。
- ファイル名、再生時間、サンプリング周波数、チャンネル数、取得できる場合はビットレートを表示する。
- 拡張子だけでなく FFprobe の認識結果とメタデータを検証する。音声全体のデコード検証は行わない。
- 選択のキャンセルや読み込み失敗時は直前の有効な選択を保持する。
- ブラウザプレビュー、FFprobe が未検出の環境では選択できない。

### Windows での確認

1. FFprobe を PATH または実行ファイルの隣に配置し、デスクトップ版を起動する。
2. 正常な MP3、空ファイル、MP3 に改名した WAV、空白・日本語を含むパスを試す。
3. 再選択、キャンセル、失敗時の表示と直前の選択保持を確認する。

## 画像読み込み（#8）

- デスクトップ版で OS のダイアログから PNG、JPG/JPEG、GIF を 1 ファイル選択する。
- Rust の image クレートで実際の形式と画像寸法を検証し、ファイル名、形式、寸法、容量を表示する。
- 選択した画像データのみを IPC で受け渡し、プレビューを描画する。画像のためにファイルシステム全体を WebView に公開しない。FFmpeg の検出状況に関係なく利用できる。
- プレビューはアスペクト比を維持する。すべての配置でアニメーション GIF は元のループ指定に従ってプレビュー再生し、動画出力時は音声の終端まで繰り返す（#10、#79）。ぼかし背景のGIFプレビューはCSSによる近似で、FFmpeg出力と完全な画素一致は保証しない。
- 暫定の読み込み上限は 32 MiB / 4000 万画素。大きなファイルの扱いは必要に応じて再検討する。
- 不正な形式、空ファイル、寸法の異常、プレビューのデコード失敗を拒否する。ただし GIF 全フレームの完全な検証は行わない。
- キャンセルや失敗の場合は直前の有効な素材とプレビューを保持する。

### Windows での確認

1. PNG、JPEG、複数フレームの GIF を順に選択し、寸法・容量とプレビューを確認する。
2. 縦長・横長・正方形の画像が枠内に収まり、縦横比を保つことを確認する。
3. 日本語や空白を含むパス、空ファイル、拡張子を偽装したファイル、破損画像を試す。
4. 選択のキャンセルや読み込み失敗で、直前の選択が維持されることを確認する。

## 静止画からの MP4 生成（#9）

- MP3 と PNG/JPEG を選択し、保存先を指定すると「MP4を生成」が有効になる。
- 出力は 1920×1080、30 FPS、H.264（CRF 20）、AAC（192 kbps）、yuv420p、faststart が初期設定（#11 で変更可能な項目を追加）。縦横比を維持する。#9 の実装時は黒帯補完、現在の既定値は #64 の中央80%・ぼかし背景。
- FFmpeg は音声終端で終了し、FFprobe で形式・解像度・フレームレート・映像と音声の尺を検証する。
- 検証済みの一時ファイルを保存先に移す。既存ファイルは上書きせず、通常の失敗では一時ファイルを破棄する。
- 生成中は素材と出力の変更を無効にし、進捗と中断を提供する（#12）。完了時に尺・容量を表示する。
- FFmpeg（libx264/AAC 対応）と FFprobe が必要。利用者が別途導入する（[環境構築とビルド](setup.md)）。

### 確認方法

1. MP3 と縦長または正方形の PNG/JPEG を選び、新しい MP4 の保存先を指定する。
2. 生成完了後、動画を再生して画像・音声・選択した配置・再生時間を確認する。
3. 素材未選択時、生成中は生成できないことを確認する。
4. 既存の MP4 を保存先に指定しても内容が変わらないことを確認する。
5. 自動結合テストは FFmpeg/FFprobe が利用可能な環境で cargo test --locked --manifest-path src-tauri/Cargo.toml video::tests::encodes_ -- --ignored --test-threads=1 を実行する。

## アニメーション GIF の MP4 合成（#10、#79）

- MP3 と GIF を選択して MP4 を生成できる。
- GIF のループ指定（なし・有限・無限）にかかわらず、元のフレーム間隔を基準に音声の終端まで反復する。
- 出力は #9 と同じ設定体系。GIF のタイミングは選択した FPS に量子化される。
- GIF のプレビューは元ファイルのループ指定に従うが、MP4 の合成は常に音声尺まで繰り返す。
- 静止画と同様に既存ファイル保護、一時ファイル処理、FFprobe 出力検証を行う。

### 確認方法

1. 短い GIF と長い MP3 を選択して MP4 を生成する。
2. GIF が元の再生時間を超えて繰り返し、音声の終端まで映像が続くことを確認する。
3. ループ指定なし・有限・無限の GIF を確認する。
4. PNG/JPEG の出力が従来通り動作することを確認する。

結合テストは GIF の実フレームをデコードし、初回と複数ループ後の色を比較して静止画化していないことを確認する。エンコードは同時に一つしか実行できないため、結合テストは直列で実行する。

## 動画出力パラメータ（#11）

- 解像度: 1920×1080 (16:9)、1080×1080 (1:1)、1080×1920 (9:16)。
- FPS: 24、30、60。映像品質: CRF 16（高画質）、20（標準）、24（容量優先）。
- 画像配置: blurred（中央80%・ぼかし背景、既定）、contain（全体表示・黒帯）、cover（中央切り抜き）。プレビューにも解像度・配置を反映する。
- 初期値は 1920×1080、30 FPS、CRF 20、blurred。AAC は従来通り 192 kbps、H.264 / yuv420p / faststart 固定。
- Rust 側で許容設定を検証し、FFprobe で出力の寸法・FPS・形式・尺を確認する。CRF はエンコード引数で指定する。
- エンコード中は設定変更不可。永続化は #20 で実装済み。

結合テストでは既定設定の PNG/JPEG/GIF に加え、正方形・24 FPS・CRF 24 と縦長・60 FPS・CRF 16・cover を確認する。

## エンコード進捗と中断（#12）

- FFmpeg の progress 出力 out_time_us と MP3 の FFprobe 再生時間から進捗を計算する。GUI は約 200 ms ごとに取得し、検証・保存完了まで最大 99% とする。
- 素材確認、生成、出力検証、保存、成功、失敗、中断を区別する。
- 中断要求を受けた場合、実行中の FFmpeg を kill/wait してから一時ファイルを破棄する。既存の出力は上書きしない。
- 素材確認中や出力検証中に中断した場合は、実行中の FFprobe 等の完了後に処理を中止する。最終保存開始後は中断できない。
- 中断・失敗時には素材と保存先を保持し、再実行できる。正常終了のみ 100% とする。
- 進捗時間解析・中断と保存の競合防止・ジョブ登録の単体テスト、実行途中の中断と一時ファイル削除、同じ保存先で再実行する結合テストを追加。

Windows 実機では長めの MP3 を使い、進捗の変化、中断、保存先に不完全な MP4 が残らないこと、同一設定での再実行、正常終了時のみ 100% になることを確認する。アプリの強制終了や OS の異常終了時の一時ファイル回収は対象外。

## ノイズ除去設定（#14）

- デスクトップ版で FFmpeg / FFprobe が利用可能なとき、ノイズ除去チェックボックスを有効にする。
- 初期状態は無効。チェック時のみ低減量・ノイズフロアを操作可能にする。
- 低減量 1～30 dB（初期値6）、ノイズフロア -80～-20 dB（初期値-50）。初期値に戻すボタンで数値のみ復元する。
- 数値はリアルタイム表示し、共通の Rust フィルタ設定検証を通す。音声素材選択後は実際のサンプルレートで検証する。
- 設定はローカルに自動保存（#20）。試聴は #17、動画への適用は #18 で実装済み。永続化は #20 で実装済み。

確認: 有効/無効、スライダーの範囲、リセット、素材再選択時の設定保持と検証表示を確認する。

## 周波数フィルタ設定（#15）

- ハイパス、ローパス、1バンドのパラメトリック EQ を個別に有効化。無効なフィルタの設定欄は操作不可。
- HPF/LPF はカットオフ、EQ は中心周波数・Q・ゲインを数値入力する。
- 音声素材のサンプリング周波数に合わせた周波数上限を表示・検証する。不正値は設定エラーを表示する。
- リセットは有効状態を保持して数値を初期値に戻す（周波数は現在の上限内に制限）。
- ノイズ除去と同一の FilterChain に設定を集約し、フィルタ別の検証結果を表示する。
- 試聴と MP4 反映は #17、#18 で実装済み。永続化は #20 で実装済み。

## 音量フィルタ設定（#16）

- ゲイン、ラウドネス正規化、ピークリミッターを独立して設定できる。初期状態は全無効。
- ゲインは -24～+24 dB、正規化目標は -24～-10 LUFS、True Peak 上限は -9～-1 dBTP、リミッターは -12～-0.5 dBFS。
- ゲインまたは正規化を有効にした際はリミッターも有効化し、必要に応じて個別に解除できる。
- 数値リセット、範囲検証、設定状態の表示に対応する。無効な項目の未入力値は共通設定の検証を妨げない。
- 最終処理順、制限事項は [音声フィルタ処理基盤](audio-filters.md) を参照。試聴とMP4出力は #17、#18。

## 音声プレビュー（#17）

- 音声素材を選択し、試聴開始位置をスライダーで指定する。最大30秒の区間を原音または加工音で再生できる。
- 再生・停止・シークは共通のオーディオコントロールで操作し、切替時は再生位置を引き継ぐ。
- 同じ区間では生成した WAV を再利用する。素材・設定・区間変更時は停止して破棄し、次回試聴時に再生成する。
- 準備中は試聴ボタンを無効化し、失敗はステータス欄に表示する。素材変更時に遅れて返ったデータは破棄する。
- Windows WebView2 での再生・切替操作は実機確認が必要。MP4 の音声加工は #18 で実装済み。

## 音声フィルタの動画出力への反映（#18）

- 出力欄に有効なフィルタ数（全無効ならなし）を表示する。
- 有効な設定は加工音の試聴と MP4 の両方に適用する。無効なフィルタはスキップする。
- 有効な数値入力の空欄・範囲外は生成開始を無効化し、Rust でも設定を再検証する。
- 生成開始時に試聴を停止し、素材・出力設定・フィルタ設定・試聴操作を無効化する。終了・中断・失敗後は再操作可能になる。
- 試聴用 WAV と出力 AAC の違いにより音質・ピークの完全一致は保証しない。Windows 実機では実楽曲でフィルタ全無効、個別有効、複数有効を試し、試聴との聴感比較と MP4 の尺・音声・中断動作を確認する。

フィルタ有効時は音声加工（進捗0～15%）と動画生成（15～99%）を分ける。進捗配分は目安であり実時間の比率ではない。いずれも中断可能で、通常の失敗・中断時は中間WAVとMP4の一時ファイルを削除する。

## ドラッグ＆ドロップによる素材読み込み（#19 / #31 / #32）

- 音声素材・ベース映像素材・追加レイヤーの各エリアに1ファイルずつドロップする。投入先で採用ストリームを決定する。同時ドロップは廃止した。
- ダイアログと共通のネイティブ検証を使う。生成中・読み込み中・無効エリアへのドロップを拒否する。
- ネイティブの物理座標を表示倍率で補正し、DOMの対象エリアを強調表示する。ブラウザではネイティブドロップを提供しない。
- 追加レイヤーはベース選択後に利用できる。音声素材の変更は試聴キャッシュ破棄と出力状態更新につながる。

確認: pnpm test でドロップ先・単一ファイル制約を確認する。Windows実機でDPI、スクロール、対象外エリア、生成中、破損素材、ダイアログとの整合を確認する。

## 設定の保存・復元（#20）

- 出力設定（解像度、FPS、配置、CRF）と全7種類の音声フィルタの有効状態・数値を、無効なフィルタの設定値も含めて自動保存する。
- 素材のパス、出力先、試聴区間、生成履歴は保存しない。起動時に素材や出力先を自動選択しない。
- Rust が Tauri のアプリ設定ディレクトリ（Windows: `%APPDATA%\\win.tiym.music-video-maker`）内の `settings.json` を管理。開発版とビルド済み版は同じアプリ識別子のため設定を共有する。フロントエンドから任意パスの指定はできない。
- JSON スキーマは version: 1 と values。全項目の型・選択肢・静的範囲・刻み幅を検証し、欠落・破損・未対応バージョンでは初期値に戻る。読込時のエラーは表示し、アプリの利用を継続できる。
- 保存前に設定全体を検証する。不正入力中は直前の有効な保存内容を保持する。音源固有の周波数上限は読み込み後に既存の検証で確認する。
- 変更時に保存し、連続編集は最新の有効な状態へ集約する。保存は順次処理し、一時ファイルへの完全な書き込み後に置換する。保存失敗時は表示し、次の変更で再試行する。保存完了表示前の強制終了では最新編集が残らない場合がある。
- 「出力・フィルタ設定を初期化」で出力を既定値、フィルタを全無効・既定値に戻して保存する。素材・保存先は維持し、試聴データを破棄して出力状態を更新する。生成中は初期化不可。ブラウザプレビューは対象外。

確認: pnpm test と cargo test --locked でスキーマ、破損・未対応バージョン、連続保存、ファイル置換・読み書きエラーを検証する。Windows 実機では設定変更・保存完了・再起動、無効フィルタの値の復元、初期化、破損 JSON からの復帰、生成中の初期化不可、試聴と出力への反映を確認する。

## フィルタプリセット（#21）

- 音声フィルタパネルで名前を入力し、現在の全7種類のフィルタの有効状態と数値（無効時の値を含む）を保存する。出力設定・素材・保存先は含めない。
- 名前は前後の空白を除去して1～40文字（UTF-16コード単位）、最大50件。大文字小文字を区別せず同名は拒否する。上書きは行わないため、更新する場合は別名で保存するか旧プリセットを削除して保存する。
- 選択後に「適用」でフィルタ設定のみ置換し、既存の設定検証・試聴キャッシュの破棄・出力更新・自動保存を実行する。プリセットの選択や名前入力だけではフィルタは変化しない。
- 「削除」は選択中のプリセットを削除するが適用済み設定は維持。「フィルタを初期化」は全フィルタを無効・初期値に戻し、保存済み一覧と出力設定を維持する。「全削除」は2回押して確定し、一覧だけを初期化する。
- プリセットは settings.json と独立した presets.json（version: 1、64 KiB上限）に保存する。既存の設定ファイルの一時ファイル置換処理を再利用し、成功後に一覧を更新する。読み込み失敗時は自動で上書きせず、明示的な全削除で復帰可能。
- プリセット操作は生成中、読み込み・書き込み中、FFmpeg/FFprobe未検出時、ブラウザプレビューでは無効。適用後の周波数上限は音源に合わせて既存の検証で確認する。既製の音質プリセットは提供せず、ユーザーが名前付きで作成する。

確認: pnpm test と cargo test --locked で複数プリセットの復元、初期化、名称・数値検証、件数制限、削除、破損・未対応形式、settings.jsonとの独立性を検証する。Windows実機では再起動、切替、削除、全削除、試聴キャッシュと出力の反映、生成中の操作禁止を確認する。

## エラー処理・診断情報（#22）

- 音声・画像の読み込み、試聴、フィルタ設定、保存先選択、動画生成・中断、実行環境、設定・プリセットの読み書きで、ユーザー向けの原因・対処方法を表示する。
- RustのI/Oエラー種別で権限不足、容量不足、パス消失、既存ファイル、Windows共有違反を識別する。FFmpeg/FFprobeは起動失敗と異常終了を区別し、stderrの代表的な英語メッセージから容量不足・権限・不正素材・不足機能等を識別する。未知の原因は断定せず操作別の案内を表示する。
- 画面下部の「診断情報（直近8件）」で操作、エラーコード、時刻、元のエラー詳細を確認できる。詳細は長さを制限し、テキストとして表示する。診断はアプリ内のみ、外部送信・ファイルへの自動保存はしない。パス等を含むため共有前に確認する。
- 失敗時は前の有効な素材・設定・保存先を維持し、試聴失敗時のキャッシュは破棄する。生成失敗・中断時は既存の一時ファイル回収と再操作可能化を維持する。中断はエラーとして記録しない。出力検証の条件は緩和しない。
- 空き容量の事前保証は行わない（加工音WAVやMP4のサイズは内容等で変わる）。実際のI/O・FFmpegエラーで案内する。

確認: Node/Rust単体テストでエラー分類、未知エラー、診断の長さ制限、中断の区別を検証する。Windows実機では破損MP3・画像、削除された素材、既存出力、書込不可フォルダ、容量不足、FFmpeg欠損・異常終了、生成失敗後の再実行と診断情報を確認する。容量不足・権限の実環境試験には専用のテストフォルダ/ドライブを利用する。

## 中央80%・ぼかし背景（#64）

- 前景は高さ80%を上限とし、横幅が画面を超える場合は画面幅に合わせて縮小する。アスペクト比を維持し中央に配置する。
- 背景は同じ画像の中央クロップで全体を埋め、ぼかし強度20相当（短辺の2%を標準偏差とするガウスぼかし）を適用する。透過部分は黒に合成する。
- PNG/JPEG/GIF共通。静止画はRustで一度合成する。GIFはFFmpegで前景と背景を動的合成し、音声終了まで繰り返す。
- 新規・設定初期化時はblurred。以前保存したcontain/cover設定は引き続き復元する。
- プレビューとMP4はRustの共通合成処理を利用する。素材・解像度・配置変更時に更新し、古い非同期プレビュー結果は破棄する。生成時は一時PNGを音声尺までループさせる。

## 追加レイヤー（#30）

- ベース映像素材を選択後、「追加レイヤー」の追加ボタンまたはドロップで対応映像素材を最大8件選択する。上が最前面で、「前面へ」「背面へ」「削除」で編集する。ベース画像は既存の選択・ドラッグ＆ドロップで置換する。
- X/Y は矩形の左上、幅/高さは矩形の大きさ。いずれも出力キャンバスに対する百分率（小数2桁まで）。画像は縦横比を維持して矩形内で中央に収まる。不透明度は整数 0～100%。
- 入力の有効な変更はプレビューに反映する。空欄・範囲外の場合は直前の有効なプレビューを保持し、修正または削除まで生成を無効にする。
- 生成中・追加素材の読み込み中はレイヤー編集を無効にする。選択キャンセル・失敗は既存レイヤーに影響しない。
- 追加GIFはプレビュー上で元のループ指定に従い、出力では音声終端までループする。CSS表示と出力の画素・同期の完全一致は保証しない。
- 素材パス・レイヤー設定は保存しない。用途別ドロップエリアで追加レイヤーも選択できる。

## 用途別ドロップエリア（#31 / #32）

音声素材・ベース映像素材・追加レイヤーの3つのエリアに1ファイルずつドロップする。音声エリアは対応動画の音声のみ、映像エリアは映像のみを採用する。動画プレビューは最大8秒・10fps・360px以内の無音ループGIF近似表示。アニメーションWebPは拒否する。

## エンコーダー選択（#40）

出力設定にエンコーダー選択、GPU再検出ボタン、検出状態を追加する。CPUが初期値で自動選択も可能。利用不可の個別GPUは無効化する（保存済みの選択だけは明示的に保持し、再試験・CPUフォールバック可能）。検出中もCPU出力を妨げない。GPU時は画質段階をCRF表記なしで表示する。生成進捗・完了に実際の方式とCPU切替、完了時に総所要時間を表示する。失敗詳細は既存の診断情報へ記録する。

## 音声解析（#33・#34）
右列のプレビューと動画出力の間に独立パネルを追加。解析ボタン、ステータス、原音/加工音波形、Peak/RMS/超過サンプル数、原音/加工音の重ね描きFFT、サンプルレート・チャンネル数・尺・FFT情報を表示。フィルタ変更時は結果をクリアし手動で再解析。Canvasはリサイズとテーマ変更で再描画。波形クリックは既存試聴スライダーに反映し、動画生成中は解析不可。解析結果はMP4出力には含めない。

## オーディオビジュアライザー（#36）
既存追加レイヤーの一覧と前面/背面/削除、位置・サイズ・不透明度を共用する。「ビジュアライザー追加」で表示形式・原音/加工音・色・背景を変更できる。スペクトログラムは色選択を無効化。素材と合計8件。静止Canvasガイドは配置・色の参考で、音楽の実波形やリアルタイム映像ではない。設定は現在の素材セッションのみ保持する。
