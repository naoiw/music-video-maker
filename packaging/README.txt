Music Video Maker - Windows x64

1. ZIP をすべて展開してください。
2. music-video-maker.exe をダブルクリックしてください。
3. MP3 と PNG / JPEG / GIF を選び、出力先を指定して動画を生成してください。

ffmpeg.exe と ffprobe.exe はアプリと同じフォルダに置いたままにしてください。
WebView2 Runtime がない場合は Microsoft 公式から Evergreen Runtime を導入してください。
https://developer.microsoft.com/microsoft-edge/webview2/
