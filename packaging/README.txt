Music Video Maker - Windows x64
===============================

【起動】
1. ZIP を右クリックして「すべて展開」を選んでください。
2. music-video-maker.exe をダブルクリックしてください。
   ffmpeg.exe / ffprobe.exe は同じフォルダに置いたままにしてください。
3. WebView2 Runtime が未導入の場合は Microsoft 公式の Evergreen Runtime を導入してください。
   https://developer.microsoft.com/microsoft-edge/webview2/

【動画を作る】
1. 「素材」の音声・画像の「選択」で MP3 と PNG/JPEG/GIF を各1つ選びます。
   エクスプローラーからのドラッグ＆ドロップも可能です。
2. 「出力設定」を確認します。初期値は 1920×1080、30 fps、
   中央80%・ぼかし背景、標準 (CRF 20) です。
3. 音声加工が不要なら全フィルタを無効にします。
   必要なら音声フィルタを有効にし、プレビューの「原音」「加工音」で
   最大30秒の試聴を比較します。
4. 「動画出力」の「保存先」の「選択」で新しい MP4 ファイル名を指定します。
5. 「MP4を生成」を押し、「生成完了」と表示されたら MP4 を再生して確認します。

【設定】
・解像度：1920×1080、1080×1080、1080×1920
・フレームレート：24、30、60 fps
・画像配置：中央80%・ぼかし背景、全体表示（余白）、画面いっぱい（切り抜き）
  GIF を動かすには全体表示または切り抜きを選びます。
・映像品質：CRF 16（高画質）、20（標準）、24（容量優先）
・出力：MP4 / H.264 / AAC 192 kbps
・音声フィルタ：ノイズ除去、ハイパス、ローパス、EQ、ゲイン、
  ラウドネス正規化、ピークリミッター。初期状態は全無効です。
・設定は自動保存されます。素材と保存先は再起動後に選択し直してください。
・「フィルタプリセット」で名前を付けて保存・適用・削除ができます。
・「出力・フィルタ設定を初期化」で出力とフィルタを初期値に戻せます。

【困ったとき】
・生成できない：素材、保存先、フィルタ設定、画面下部の「実行環境」を確認します。
・素材エラー：正常な MP3、32 MiB以下・4000万画素以下の PNG/JPEG/GIF を選び直します。
・保存エラー：別のファイル名、書き込み可能なフォルダ、空き容量を確認します。
  既存の MP4 は上書きされません。
・中断：「中断」を押して処理が終わるまで待ちます。最終保存中は中断できません。
・原因不明：画面下部の「診断情報（直近8件）」でエラーコードと詳細を確認します。
  ファイルパスなど個人情報を取り除いてから問い合わせてください。

元の MP3・画像は変更しません。素材を外部へ送信しません。
YouTube へのアップロードはアプリでは行いません。
